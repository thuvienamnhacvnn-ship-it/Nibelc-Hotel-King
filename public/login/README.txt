Ảnh banner trang đăng nhập — thả file vào thư mục này là tự dùng, không cần sửa code:
  banner-desktop.webp (hoặc .jpg/.png)  máy tính, nửa trái màn hình — gợi ý 1600×1800 px
  banner-mobile.webp  (hoặc .jpg/.png)  điện thoại, phần trên màn hình — gợi ý 1170×1000 px
Chưa có file thì trang dùng nền trang trí navy.
